# 夜航快递 NIGHTLINE EXPRESS

- 引擎：Godot 4.7.2（minSdk 24 / targetSdk 36）
- 版本：v0.2.0，更新日期 2026-09-15
- 形态：**横屏**（sensor_landscape），离线单机，零额外权限

## 玩法

午夜微缩铁路调度游戏：扳道岔、看信号、安排发车，
把乘客送到对应「颜色 + 形状」的车站。
含 12 关战役 + 种子挑战，美术与音频全部程序化原创。

## v0.2.0 修了什么

上一版交付后复现并修复 27 项缺陷，其中 4 项致命：

1. **HUD 全部面板不显示** —— 关卡初始化时给 `SystemFont` 赋了 Godot 4 不存在的属性，
   运行期报错当场中断初始化，导致左上进度条、左下「需求预告」、底部选中列车面板、
   顶部目标条全部不显示（这是"看不出在调整什么"的主因）。
2. **按 Android 返回键直接退出、丢进度** —— 现已改为「先关浮层，再开暂停菜单」，绝不退出进程。
3. **列车停在道岔前会把该道岔永久锁死**，玩家除重开别无出路。
4. **每次发车沿边瞬移**，会越过其它泊位并压到停稳的车身上。

手机可读性（本次重点，保持横屏）：
镜头改为贴合"轨道内容包围盒"取景（缩放 1.0 → 约 1.3~1.5），
轨道 / 道砟 / 枕木 / 信号灯 / 道岔方向箭头全面加粗放大，
点击热区（道岔/信号/列车/车站）同步扩大到 42/42/32/36 世界单位，
站台图形按站台边长度铺满（原来只有实际泊位区的 1/4，2、3 号泊位的列车看着停在站台外）。

另外修复：两车抢同一泊位（互相顶在车头上）、信号灯红灯形同虚设、
读档后等待泊位的列车永久卡死、暂停菜单「重开」无效、全游戏中文提示一条都不显示、
关卡解锁判定错位且可跳关、最后一关点「下一关」静默重开同一关、
种子挑战输入框打不了字、结算面板被返回键关掉、音量滑条不可拖动等。

验证：`validate-campaign` 12/12 通过；`selftest` 11/11 通过
（上一版为 10/11，"全部关卡无穿模/重叠"由 0.7 单位转为 74 单位）；
模拟器 2400×1080 横屏在 release 包上完成主菜单/选关/进关/返回键/重开/设置/种子输入回归，
logcat 无 FATAL 与 SCRIPT ERROR。真机与帧率仍未实测。
