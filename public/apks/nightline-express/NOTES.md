# 夜航快递 NIGHTLINE EXPRESS

- 引擎：Godot 4.7.2（minSdk 24 / targetSdk 36）
- 版本：v0.2.0（第三轮修订，2026-09-15）
- 形态：**横屏**（sensor_landscape），离线单机，零额外权限

## 玩法

点站台里的列车发车，把每位乘客送到他身上「颜色 + 形状」标记对应的那一站；线路冲突时点道岔改连通方向、点信号灯切换红绿。12 关战役 + 种子挑战，美术音频全部程序化原创。

**第一次打开会直接弹出「怎么玩」**，主菜单也常驻同名按钮。

## 第三轮：把卡死的关卡救回来

上一轮实测发现 c04 / c09 / c11 在送达 3 位之后再也送不出第 4 位。这一轮定位到两个真正的根因并修掉：

1. **目的地不可达把列车永久锁在站里**：选目的站时只看「哪站人多」，不检查能不能开到。c04 十字路口的路口配对会让某些站当时不可达，两列车于是双双停在站里直到超时。现在选目的地会跳过不可达的站（玩家和自动调度器都受益）。
2. **站台泊位互相堵死**：站台是单线死头，外侧泊位被占时内侧泊位其实进不去；指派进去的列车会卡在半路，把停在里面的车也一起堵死。现在会把这种泊位判为不可用。
3. 出站判定留了 8 单位容差，等在站台入口的车不算「堵路」——否则「站里的车出不去、门外的车进不来」会互相锁死。


实测产能（基准调度器跑满限时）：**c04 从 3 → 78、c09 从 3 → 41、c08 从 9 → 13**。
c11「夜班繁忙」三列车在雪镇合流处仍会互锁，产能上限只有 3~6，因此把它的通关线按实测可稳定达到的量调整（5 → 3），不再是一关必输局。


## 前两轮改了什么

- 通关即结束的致命逻辑缺陷：原来送达数一到「通关线」就立刻结算，而通关线 = 一星线，乘客每次下车又是 3 的整数倍 —— 第一关永远停在 6/5、永远 2 星，三星线根本够不着。现在达成通关线只提示不结束，继续送可以冲 2 星 / 3 星；送满三星立即完美结算，也可以随时点右上「收工」按当前成绩结算。
- 目标文案收敛成一处：删掉顶部那条和目标重复、说法还不一样的文字，目标信息统一在左上角一个面板说完 —— 关名 / 剩余时间 / 已送达 N 位 / 通关线 N 位 / 星级阶梯 / 「再送 N 位到 X 星」。
- 星级阈值按实测产能重标定。
- 新手引导：首次启动直接进「怎么玩」页，四步讲清玩法。
- 正反馈：送达 / 上车时在列车位置弹出「+N 送达」「+N 上车」飘字；达成通关线有横幅提示；通关后右上出现「收工」按钮。
- 文案与实现对齐：此前「关于」页宣称「送到对应颜色+形状的车站」，但程序里只比对目的站，颜色形状并不参与判定，现在文案改成事实描述。


## 已知问题（重要）

- **c11「夜班繁忙」仍有合流互锁**：三列车在雪镇入口会互相占住，实测产能上限 3~6 位；通关线已按此下调，能通关但打不出高星。
- **「颜色 + 形状配对」目前只是「去向标记」**：站牌与乘客用同一套标记，方便一眼认出乘客要去哪一站，但判定上仍然是「送到目的站」。要把它做成真正的配对规则（跑错站就送不掉），需要改判据 + 重写全部需求波次，是独立一轮的工作量。
- 真机与帧率仍未实测（本机没有 ARM64 真机）。
