# 夜航快递 NIGHTLINE EXPRESS

- 引擎：Godot 4.7.2（minSdk 24 / targetSdk 36）
- 版本：v0.2.0（第四轮修订，2026-09-15）
- 形态：**横屏**（sensor_landscape），离线单机，零额外权限

## 玩法（这一轮把玩法真正做出来了）

1. **每家车站门口挂着本店的徽章：颜色 + 形状**（例如「灯塔 = 珊瑚红·三角」）。
2. **每位乘客身上也有一枚一模一样的徽章 —— 那就是他要去的那一站**。全关徽章两两不同，同一关里形状也不重复，所以看形状就能认站，不依赖辨色。
3. **点一下站台里的列车 = 选中它；再点一家车站 = 送他去这一站**。再点一次列车本身 = 让系统自动挑站发车（懒得选时用）。
4. 到站后**只有徽章相符的乘客会下车**并计入「已送达」，其余留在车上。线路冲突时点道岔改连通方向、点信号灯切换红绿。

**第一次打开会直接弹出「怎么玩」页**，主菜单也常驻同名按钮。

## 第四轮：把「颜色+形状配对」做成真规则（并加了短区段死锁避免）

上一轮我发现一个尴尬的事实：README 和「关于」页一直宣称「把乘客送到对应颜色+形状的车站」，但代码里只比对目的站 id，颜色和形状从头到尾是随机装饰 —— 实测 12 关 413 条需求波次里只有 165 条（40%）的颜色和目的站对得上，c03/c04 甚至是 0%。也就是说，这个玩法从来没有被实现过。这一轮把它补上了：

- **车站获得唯一徽章**：站点数据加了 shape 字段，同一关内形状两两不同（≤6 站时形状本身就唯一识别一个站）。
- **乘客徽章一律由目的站派生**（在 builder 构建关卡时统一改写），所以全 12 关自动一致，不用逐条改 413 条数据。新增校验脚本：**413/413 波次徽章与目的站一致，0 关有问题**。
- **下车判据改成比徽章**：乘客与车站的（颜色, 形状）都相符才下车。
- **站牌挂上徽章**：站名牌左边画的就是本站徽章，和乘客身上的标记一一对应。
- **玩家可以指定目的地**（新的核心操作，见上面玩法第 3 条），并新增 `depart_to` 指令，回放可复现。点车站时还会用中文报出徽章：「灯塔（珊瑚红·三角 徽章）有 3 位乘客候车」。
- 首关三句教学完全重写，教的就是「徽章=目的站 → 选车点站 → 徽章相符才下车」。

## 第三/五轮：卡死的关卡全部修复

c04 / c09 / c11 原本在送达 3 位后彻底卡死。定位到两个代码根因并修掉：目的地不可达时列车被永久锁在站里（c04 十字路口）；站台泊位互相堵死（单线死头，外侧被占时内侧进不去）。实测产能：**c04 从 3 → 78、c09 从 3 → 41、c08 从 9 → 13**。c11 的合流互锁也修好了（等泊位的车不再堵死站台咽喉）。
