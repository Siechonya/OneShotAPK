# 夜航快递 NIGHTLINE EXPRESS

- 引擎：Godot 4.7.2（minSdk 24 / targetSdk 36）
- 版本：v0.2.0（第二轮修订，2026-09-15）
- 形态：**横屏**（sensor_landscape），离线单机，零额外权限

## 玩法

午夜微缩铁路调度：点站台里的列车发车，把每位乘客送到他身上「颜色 + 形状」标记对应的那一站；线路冲突时点道岔改连通方向、点信号灯切换红绿。12 关战役 + 种子挑战，美术音频全部程序化原创。

**第一次打开会直接弹出「怎么玩」**，主菜单也常驻同名按钮。

## 第二轮改了什么（针对「看不懂目标 / 没有新手引导 / 没正反馈」）

1. 通关即结束的致命逻辑缺陷：原来送达数一到「通关线」就立刻结算，而通关线 = 一星线，乘客每次下车又是 3 的整数倍 —— 第一关永远停在 6/5、永远 2 星，三星线 7 根本够不着。现在达成通关线只提示不结束，继续送可以冲 2 星 / 3 星；送满三星立即完美结算，也可以随时点右上「收工」按当前成绩结算。
2. 目标文案收敛成一处：删掉了顶部居中那条和目标重复、说法还不一样的文字，目标信息统一在左上角一个面板说完 —— 关名 / 剩余时间 / 已送达 N 位 / 通关线 N 位 / 星级阶梯 / 「再送 N 位到 X 星」。
3. 星级阈值按实测产能重标定：以基准调度器跑满限时的实际送达量为锚（第一关 42、环城夜线 87…），原来的 5/6/7 改成有意义的三档。
4. 新手引导：首次启动直接进「怎么玩」页，四步讲清「乘客标记=目的站 → 点车发车 → 道岔/信号怎么用 → 左上角那个面板就是全部目标」。
5. 正反馈：送达 / 上车时在列车位置弹出「+N 送达」「+N 上车」飘字；达成通关线有横幅提示；通关后右上出现「收工」按钮。
6. 文案与实现对齐：此前「关于」页宣称「送到对应颜色+形状的车站」，但程序里只比对目的站，颜色形状并不参与判定，现在文案改成事实描述。
7. 另外修掉两处会互相锁死的过严规则、一处「停住的车永久预约下游区段」的缺陷，以及僵局检测被微小蠕动骗过（卡死 4 分钟都不结算）。

验证：validate-campaign 12/12、selftest 11/11、gen-filter 18 试 6 收；穿模判据改用「车身折线是否相交」（12 关车身相交帧数 = 0）。

## 已知问题（重要）

- **c04「十字路口」、c09「雪原枢纽」、c11「夜班繁忙」存在不可恢复的死锁**：实测即使每 3 秒轮转全部道岔与信号、并手动点每一辆待发的车，这三关在送达 3 位之后就再也送不出第 4 位。其中 c04 全关没有任何道岔和信号，路口一旦互锁就无解。现在它们会在僵局 12 秒后结算（已通关按收工算，未通关判僵局），不会干等，但根因需要单独一轮重新设计关卡。**建议先玩 c01–c03、c05–c08、c10、c12。**
- 真机与帧率仍未实测（本机没有 ARM64 真机）。
